# Task 03 – Network Traffic Analysis

## Objective

To capture and analyze network traffic using Wireshark and identify common network protocols and communication patterns.

## Environment

- Kali Linux
- VirtualBox
- Wireshark
- Firefox
- Terminal

## Activities Performed

- Captured live network traffic
- Analyzed TCP traffic
- Analyzed DNS queries and responses
- Inspected HTTP/HTTPS traffic
- Examined packet details
- Observed ICMP and ARP traffic
- Used Wireshark display filters
- Validated network communication using curl

## Tools Used

- Wireshark
- Kali Linux
- Firefox
- curl
